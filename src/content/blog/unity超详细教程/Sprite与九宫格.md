# Sprite 与九宫格

---

## 1. 为什么叫"精灵"（Sprite）？

这个词直接翻译成中文是"小仙子、小精灵"，这个叫法源于 70-80 年代的早期游戏开发。

- **背景限制**：那时的计算机性能很弱，无法像现在这样逐帧重绘整个复杂画面。如果背景和人物都画在一张大图上，人物每动一下整个画面都要重算，根本跑不动。
- **技术解法**：工程师们把游戏中**可以独立移动的图形对象**（主角、敌人、子弹）和**固定的背景**分离开，交给专门的硬件去处理。这些独立的图形对象就像舞台上的演员，由硬件合成显示。
- **为什么叫"精灵"**：因为这些小人、飞船在屏幕上轻巧地飘来飘去，不受背景束缚，就像童话里会魔法的小精灵。它们不是背景画的一部分，而是有独立"生命"的小玩意儿。这个叫法就这么形象地流传了下来。

---

## 2. 纹理（Texture）vs Sprite

在 Unity 里，这两者有非常关键的区别，也是初学者容易混淆的地方：

- **纹理（Texture）**：就是存储在硬盘上的 PNG/JPG 图片文件本身。它只是一块"原料"。
- **Sprite**：从纹理上裁切出来的、能被 Unity 当作 2D 对象直接使用的**资源**。它具备演员的"属性"——位置、旋转、缩放等。

导入图片后，你需要在 Inspector 中把它的**纹理类型**改成 **Sprite (2D and UI)**，这张图片才真正变成一个"精灵图"。

### 用比喻来巩固记忆

| 概念 | 比喻 |
| :--- | :--- |
| 纹理 | 一块印着各种图案的**布料** |
| Sprite | 用这块布剪下来的一个**纸片演员** |
| Sprite Renderer | 把纸片演员粘在小木棍上让它显示的**组件** |
| Animator | 快速替换不同纸片让它动起来的**动画师** |

---

## 3. Sprite Renderer（精灵渲染器）

这是让精灵在场景中被看到的核心组件。选中一个精灵后，可以在 Inspector 的 Sprite Renderer 组件中：
- 更换显示的精灵图
- 调整颜色
- 设置排序层级（决定谁挡住谁）
- 翻转图片

---

## 4. Sprite Sheet 切割步骤

当你拿到一张包含多个角色动作帧的大图时，需要进行切割：

1. 在 Project 面板中**选中**那张大图
2. 在 Inspector 中设置以下参数：
   - **Pixels Per Unit（每单位像素）**：设为 `64`（值越小精灵在场景中越大）
   - **Sprite Mode**：设为 `Multiple`（多个），表示这张图包含多个精灵
   - **Filter Mode（过滤器）**：设为 `Point (no filter)`，**取消模糊效果**，适合像素风格游戏
   - **Format（格式）**：设为 `RGBA 32 bit`，保证色彩质量
3. 点击 **Sprite Editor** 按钮打开图像切割编辑器
4. 在切割编辑器中选择切割方式（按网格或按单元格大小），切割成单独的帧

## 5. 九宫格拉伸

### 问题重现

你有没有遇到过这样的情况：
1. 在精灵编辑器里辛辛苦苦调好了绿色的 Border（边框）框
2. 满心期待地把图片拖进场景
3. 用鼠标拖动四角改变大小
4. 结果——**整个图还是等比例缩放了，四角全变形了**

明明跟着教程设置了九宫格，为什么没效果？难道是 Unity 出 bug 了？

### 一句话答案

**Sprite Renderer 组件不支持九宫格拉伸。**

你设置的 Border 没有错，只是你用错了显示方式。

### 为什么会这样？

Unity 里不同的组件，对精灵图 Border 的支持情况完全不同：

| 组件类型 | 九宫格支持 | 使用场景 |
| :--- | :---: | :--- |
| **Sprite Renderer** | ❌ 不支持 | 场景中普通的 2D 精灵物体 |
| **UI Image** | ✅ 支持 | Canvas 下的 UI 元素 |
| **Sprite Shape** | ✅ 支持 | 可拉伸变形的 2D 形状 |

当你把一张图拖入场景时，Unity 默认给它添加的是 **Sprite Renderer** 组件。而这个组件不认识你在精灵编辑器中设置的绿色 Border，只会把整张图当作一个整体来缩放。

### 正确做法：用 UI Image

如果血条、按钮、对话框需要九宫格拉伸，应该用 **UI Image** 组件：

1. **创建 Canvas**：在 Hierarchy 右键 → **UI** → **Canvas**
2. **创建 Image**：右键 Canvas → **UI** → **Image**
3. **设置 Source Image**：选中 Image，在 Inspector 把 `Source Image` 设为你设置过 Border 的精灵图
4. **切换为 Sliced 模式**：将 `Image Type` 从 `Simple` 改为 **`Sliced`**
5. **拖动测试**：用 Rect Tool（快捷键 T）拖动这个 Image 的边角，你会发现四个角终于保持不变，只有中心被拉伸了

### 不想用 UI 怎么办？

有些情况下你需要把可拉伸的物体放在场景世界坐标中（比如跟随角色移动的血条、可伸缩的平台等），有两个办法：

#### 方法一：World Space Canvas

将 Canvas 的 `Render Mode` 设为 **World Space**。这样 UI 元素就能像普通 2D 物体一样放在场景中，同时仍然支持九宫格。

#### 方法二：Sprite Shape

如果是做可拉伸的地面、管道、藤蔓等场景物体，可以安装 2D Sprite Shape 包，用 **Sprite Shape** 组件实现类似效果。

### Border（绿框）的设置逻辑

- **蓝框**：物理切割，决定图片的哪一部分被使用
- **绿框（Border）**：从蓝框边缘向内缩进的距离，划分九宫格
- **绿线到蓝线的区域**：受保护，不会变形（四角 + 四条边）
- **绿线包围的内部区域**：被拉伸的"柔软肚子"

口诀：**蓝框裁切，绿框保护。Sprite Renderer 不认绿框，UI Image 选 Sliced 才生效。**

## 6. 相关术语全家桶

- **Sprite Sheet**：一张大图，里面整齐排列着角色的多个动作帧。把它的纹理类型设为 Multiple 并切割，就能得到一系列精灵。
- **Pixels Per Unit**：精灵资源上的核心参数。它定义"图像上的 100 个像素在游戏世界里等于多少单位"。决定了精灵在场景中显示的大小，是协调所有资源比例的关键。
- **Sprite Atlas**：把多个独立的精灵图合并成一张大图，优化渲染性能。
