# Package 包管理器

---

## 1. 包（Package）是什么？是 C++ 里的库吗？

**对，本质上就是库，但更"重"一点，而且自带 UI。**

可以这样类比：

- **C++ 库**：你 `#include` 一个头文件，链接 `.lib/.a`，然后就能调用它的函数。功能是纯代码的，调用方式完全由代码决定，IDE 不会凭空变出一个按钮。
- **Unity 包**：它不仅包含 C# 代码（这是它的"库"部分），还经常包含**编辑器扩展、资源、预制件、着色器**等。一个包可以做到：当你安装它的那一刻，Unity 编辑器的菜单栏、检视面板或者项目视图里，就**立刻出现新的按钮、新的界面、新的可拖拽组件**。

你提到的脚本里写一个新接口，面板上就多一个按钮，这恰恰是 Unity 最核心的"可视化+反射"机制在起作用。包，就是把这个机制发挥到极致的**打包方式**。

- **纯 C++ 库**：给你一把锋利的刀，你必须自己记住刀法口诀，然后手写代码去切菜。
- **Unity 包**：给你一个"切菜机"，安装后，你的厨房操作台上会直接**多出一个带按钮的机器**，按一下它就切好。它把复杂的调用过程封装成了可视化的工具。

所以，加入一个新包，很多时候就是直接解锁了一种可视化功能，或者提供了一批可直接拖拽使用的、带 UI 界面的"超级组件"。比如安装 `Cinemachine` 包，就能直接在摄像机上添加一个带无数可视化引导线的智能组件。

## 2. "Unity 注册表"是什么意思？

可以把它想象成**应用商店**。

包管理器界面左边那一栏，就是选择"逛哪个货架"的地方：

- **In Project（项目中）**：这就是"**我正在用的东西**"。显示的是你当前项目已经安装好的包。默认打开停在这里，让你看看项目里已经有什么，而不是让你添加新东西。这就像你打开手机"设置 → 应用管理"，看到的是已安装的应用列表。
- **Unity Registry（Unity 注册表）**：这就是"**官方应用商店**"。这里列出的是 Unity 科技公司官方发布、审核过的所有免费可用包。你想加新功能，就必须切换到这个地方，才能浏览和下载。**注册表**这个词，就是"官方包目录服务器"的意思。
- **My Registries（我的注册表）**：如果你有自己的私有包服务器，就在这里。初学者暂时不用管。

安装包的步骤：
1. 点击菜单栏 `Window` → `Package Manager`
2. 在左上角选择 `Unity Registry`
3. 浏览或搜索需要的包
4. 点击右下角的 **Install** 按钮

## 3. 关于排序选项

顶部那一行的排序选项，纯粹是对当前列表的整理方式：

- **`sort: name (asc)`** = 按名称升序排列（A → Z）
- **`sort: name (desc)`** = 按名称降序排列（Z → A）
- **`sort: published date`** = 按发布日期排列（最新的在最前）

`asc` 是 `ascending`（升序）的缩写，`desc` 是 `descending`（降序）的缩写。这只是把货架上的东西按不同顺序摆好方便查找，不改变任何实质内容。

## 整体运作流程

1. **你有一个项目** = 你有一个 C++ 工程
2. **你想加个新功能**：比如高级相机系统
3. **在 Unity 里怎么做？**
   - 打开包管理器，左边点 **Unity Registry**（去官方商店）
   - 在列表中找到 **Cinemachine**
   - 点 **Install**
   - **瞬间**：项目中多了 Cinemachine 的相关组件，菜单栏也出现了对应选项，不需要配置任何依赖路径

## 常用包一览

在 2D RPG 开发中，你可能会用到以下包：

| 包名 | 用途 |
| :--- | :--- |
| **Cinemachine** | 智能相机系统，跟随玩家、设置边界 |
| **TextMeshPro** | 高级文本渲染，比默认文本更清晰、更灵活 |
| **Input System** | 新版的输入系统，支持更多输入设备 |
| **2D Sprite Shape** | 可拉伸变形的 2D 形状 |
| **2D Tilemap Extras** | Tilemap 的额外功能（如规则 Tile、动画 Tile） |

参考：[[unity总教程]] 中提到的各系统都会在相应阶段使用到这些包。
