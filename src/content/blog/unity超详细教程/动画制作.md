# 动画制作

---

## 创建动画的入口

1. 点击菜单栏 `Window` → **Animation** → **Animation**，打开动画窗口
2. 在 Hierarchy 中选中一个对象（比如 Player）
3. 点击 Animation 窗口里的"创建"按钮，选择存储位置并命名动画文件

---

## 制作动画

### 待机动画

1. 将精灵图直接拖放到 Animation 窗口的时间轴里
2. **按住 Shift** 将需要的帧图全部选中并放入
3. 全选所有帧后，**拖拽最后一帧后面的边界**来减缓动画的播放速度（拉得越长相同时长里看到的画面越久，速度越慢）
4. **处理循环问题**：直接放入后最后一帧播完后会立马跳到第一帧重新开始，所以最后一帧的持续时长其实只有一瞬间。解决方法是把第一帧复制一个放到末尾，延长最后一帧的显示时长，让循环看起来更自然

### 行走动画

1. 在 Animation 窗口左上角点击下拉菜单，选择 **Create New Clip**（创建新片段）
2. 命名新的动画片段（比如 "Walk"）
3. 按照待机动画的方式将行走的帧图拖入时间轴

> **角色制作流程**：建议先放入一帧精灵图作为静态默认状态，然后再选中这个角色创建动画。先后顺序就是这样的。

## Animator（动画控制器）

Animator 本质上是一个**状态机**，控制着在什么条件下播放什么动画。

### 基本概念

- **橙色状态**表示默认状态（Default State），游戏开始时角色会播放这个动画。随时可以右键点击一个状态将其设置为默认状态
- 通过创建条件和过渡，可以在多个状态之间来回切换

### 设置参数

1. 在 Animator 窗口中，点击左侧的 **Parameters**（参数）选项卡（和文件列表在一起）
2. 点击加号（+），创建两个 `float` 类型数据：`horizontal` 和 `vertical`

> **关于 Parameters**：创建的是全局的参数，而不是针对某个动画的。这也是为什么参数有单独的窗口。我们只是借用了这个一直存在的参数来做状态的判断。

### 创建过渡

1. **从待机到行走**：右键点击待机状态，选择 "Make Transition"（创建过渡），拖拽到行走状态
2. 点击这条过渡线，在右下角的 **Conditions**（条件）位置点击加号
3. 选择条件："horizontal" 参数 **Greater**（大于）0.1
4. 再添加一个纵向判断：需要再次右键创建过渡（而不是在同一条线上操作添加），选择条件 "vertical" 参数大于 0.1
5. 此时过渡线条上会出现三个箭头，对应两个不同的条件

### 从行走到待机的反向过渡

1. 从行走状态创建回到待机状态的过渡
2. 此时需要添加**两个条件**（horizontal 小于 0.1 和 vertical 小于 0.1），因为判断停止需要两个条件同时为真
3. 条件选择 **Less**（小于）0.1

## 代码控制动画参数

制作动画时需要用到两个参数来检测输入，现在需要让脚本能够改变这些参数的值，让它们真实反映玩家的实际动作。

1. 首先创建一个对动画控制器的引用：
   ```csharp
   public Animator anim;
   ```
2. 在移动代码中把输入值传递给动画控制器：
   ```csharp
   anim.SetFloat("horizontal", horizontal);
   anim.SetFloat("vertical", vertical);
   ```
3. 回到 Unity，点击玩家对象。在玩家移动脚本组件中多了一个动画控制器的选框。将玩家的 Animator 组件直接拖拽到这个接口位置

---

## 退出时间（Exit Time）和持续时间（Transition Duration）

- 在过渡的 Settings 中，如果勾选了 **Exit Time** 就会有退出时间，导致动画切换有延迟
- **取消勾选** Exit Time，并将 **Transition Duration**（过渡持续时间）设为 0，动画就能立即切换
- 对从待机到行走的两个过渡（条件）都进行此操作
- 反向过渡也同样设置

---

## 反向移动时也需播放动画

当我们正向输入时数值为**正**，可以正常触发动画条件。但反向输入时数值为**负**，动画控制器不需要知道正负方向，只需知道"有没有在移动"。所以需要将数值设置为**绝对值**：

```csharp
anim.SetFloat("horizontal", Mathf.Abs(horizontal));
anim.SetFloat("vertical", Mathf.Abs(vertical));
```

`Mathf.Abs` 的作用是取绝对值，无论输入是正还是负，都会变成正数传递给动画控制器。

## 翻转角色

### 局部缩放方法

将 Transform 组件里的 Scale 的 X 坐标改为 **-1**，角色就会水平翻转。

### 代码翻转

1. 创建一个变量来记录面朝的方向（`facingDirection`）
2. 在 Update 中检测方向变化，需要翻转时调用翻转方法
3. 不能只修改局部缩放的单个变量，必须改变整个向量

核心逻辑：

```csharp
// 检测是否需要翻转
if (horizontal > 0 && facingDirection < 0 ||
    horizontal < 0 && facingDirection > 0)
{
    Flip();
}

// 翻转方法
void Flip()
{
    facingDirection *= -1;
    transform.localScale = new Vector3(facingDirection, 
                                        transform.localScale.y, 
                                        transform.localScale.z);
}
```
