## 添加资产

- 直接拖动到资产文件夹（Assets）里即可
- 添加了一组精灵图（[[Sprite]]），需要进行分割。
	- 点击父文件（未分割图像）进行设置
		- *Pixels Per Unit*（每单位像素）： 64
		- *Sprite Mode*： `Multiple`（多个）
		- 下方可以点击 *open sprite editor* 打开图像切割编辑器
		- *filter*（美/ ˈfɪltər /）（过滤器）： `Point (no filter)` 可以取消模糊
		- *format*： `RGBA 32 bit` 色彩模式

## 添加新的包 ([[Package]])

- 点击导航栏的 `Window -- Package Management -- Package Manager`
- 选择 `Unity Registry`（注册表）

## 制作地图 `Tilemap`

- 将地形精灵图切割好
- 在层级视图中`右键 -- 2D Object -- Tilemap -- Rectangular`
	- rectangular : 矩形
	- *此时创建的叫做 `grid` （网格）*
- 开始铺图块之前，先创建一个实际的图块调色板
	- `window -- 2D -- Tile Palette`
		- palette(美/ ˈpælət /): 调色板
	- [[创建调色板]]
	- 在不同的图层绘制对应的地图
	- 给有高度的图层添加 `Tilemap Collider 2D` 碰撞体组件
		- 在左侧的 gird 网格下的 内容选择
		- 会自动映射到这个图层下的所有图块

## 瓦片地图的前景层和背景层

- 为了方便管理不同高度
- 可以分别新建不同的瓦片地图，分别对应不同的图层，全都放置在 Grid 下
- 通常会有
	- `Collision-Low` 低碰撞层： 渲染在玩家下方且可碰撞
	- `Collision-High` 高碰撞层： 渲染在玩家上方且可碰撞
	- `Non-Collision-Low` 低非碰撞层： 渲染在玩家下方且不可碰撞
	- `Non-Collision-High` 高非碰撞层： 渲染在玩家上方且不可碰撞

## 创建多层级瓦片地图

- 2D游戏显示出来全部是平面，因此需要使用触发器手动调整角色的层级来实现高度的模拟效果
- 具体思路为： 
	- 在低碰撞层创建几个方盒碰撞器，放置在**楼梯**这样的地方，就设置成一条很细的矩形像一条线一样，然后设置成**触发器**模式（`Is Trigger 打勾`）
		- 触发器： 就是作为一个区域检测碰撞的，可以进去不会阻挡，像红外光一样的效果
	- 然后再新建一个层级专门用来放置出口，因为入口应该是在楼梯的尽头，而出口应该是在楼梯的开始，如果没有完全走过楼梯其实是不会真正进入另一层的
		- 这个层级可以放在低碰撞层下级，方便整理
	- 然后编写[[层级切换脚本]]（`Elevation_Entry`和`Elevation_Exit`），
		- 记得添加脚本然后将对应的层级拖入进接口
	- 然后新建一个边界层级，用来作为高度层级的边界。
		- 因为层级切换脚本的逻辑就是将玩家的显示层拉高，然后将原先山脉这种有高度的层级的碰撞体取消
		- 这样的话因为所有的碰撞体都被取消了所以可以直接从山上走下来，本来就是2D的
		- 所以需要一个新的边界来挡住玩家不会从山上走下来
		- 使用平整一点的瓦块都可以围上一圈，然后将透明度设置为0伪装起来
		- 使用层级退出脚本控制循环即可

## 相机跟随`Cinemachine`

- 一开始想要先快速的让相机跟随，比如先看看场景如何，可以直接将相机拖入到玩家的子物体，这样就会一直保持跟随
	- 但玩家一旦翻转或销毁，相机也会做同样的事
- 所以可以使用`Cinemachine`虚拟相机
	- 包含在另一个**同名包**里
	- 在层级视图里 `右击 -- Cinemachine -- Targeted Cameras -- Fellow Camera`或者其他几个都可以
	- 在 `Cinemachine Camera` 组件里的的 `Tarcking Target` 里拖入玩家
- 设置**边界**
	- 新建一个空物体命名为`Confiner（边界器）`， 然后添加`Polygon Collider 2D` 组件，初始为五边形，长按 `CTRL` 可以点击删除任意边，添加顶点直接拖动即可。
	- 然后将边界拖入到虚拟相机的 `Cinemachine Confiner 2D` 的 `Bounding Shape 2D` 位置


> [!NOTE] **注意 ! ! !**
> - 在虚拟相机的 `Cinemachine Camera` 组件下的 `Lens` 位置设置相机大小， `Scene` 视图里会显示一个框为预览，这个框必须小于 `Confiner` 的大小，否则会导致相机初始即超出边界且无法避免，导致相机被卡住出现bug。

## 敌人追逐玩家与仇恨范围

- **基础设置**
	- 将敌人刚体组件里的 `Body Type` 设置为 `Dynamic`
	- 将敌人的 X, Y 解开锁定
- **创建[[敌人移动脚本Enemy_Movement]]
- 给敌人添加一个圆形碰撞体 `Circle Collider 2D` 作为视野区域
	- 可以设置会偏向敌人的前方而不是后方，模拟视野范围
	- 记得设置为触发器
- 这个碰撞体其实不是最好的选择
	- 可以在敌人下方新建一个空物体
	- 然后将这个空物体作为中心设置一个半径，调整位置作为视野范围
	- 为什么要这样做？
		- 有些时候人物的观察区域和自身位置是分开的，比如很长的巨型虫子，观察区域应该在头部，使用一个新的物体非常方便管理
		- 然后在脚本中添加辅助线在scene中打开辅助线就可以看到范围了
	- 其实大部分都是在脚本里，详细看脚本就可以了
	- 这里笔记真的不好写啊我靠
	- 敌人需要一个状态机管理系统，控制从待机到追逐到发动攻击的不同状态
	- 然后需要一个攻击间隔
	- 然后需要一个攻击范围判定
	- 然后可以添加击退和眩晕
