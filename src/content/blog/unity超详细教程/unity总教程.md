# Unity 2D RPG 游戏开发教程 · 总索引

欢迎！这份教程将带你一步步制作一个完整的 2D RPG 游戏。本文档是整个教程的**入口和总索引**，从这里你可以了解到一个 2D 游戏由哪些系统组成，以及每个系统对应哪些知识点和脚本文档。

---

| 相机系统    | 让镜头跟随玩家并限定边界   | Cinemachine                   | [[脚本_Cinemachine相机]]                                                                 |
| 玩家控制    | 移动、翻转、动画切换     | Rigidbody2D、Input、Animator    | [[脚本_PlayerMovement]]                                                                |

## 分点索引

### 1. 项目创建与引擎基础

学习 Unity 的第一步是熟悉编辑器界面。你需要了解五个主要面板（Scene、Game、Hierarchy、Project、Inspector）各自的作用，以及 GameObject 和 Component 这两个最核心的概念。

→ 详细内容请见 [[unity引擎基础]]

### 2. 资源导入（Sprite）

游戏中的所有图片资源都需要导入 Unity 并进行正确的设置。你需要了解 Sprite 是什么、纹理和 Sprite 的区别、如何切割 Sprite Sheet，以及 Pixels Per Unit、Filter Mode 等关键参数的设置。另外，九宫格拉伸是 UI 制作中的重要技巧。

→ 详细内容请见 [[Sprite与九宫格]]

### 3. 包管理器

Unity 的包管理器（Package Manager）是安装官方功能包的地方，比如后面需要用到的 Cinemachine、TextMeshPro 等都在这里安装。理解 Unity Registry（官方注册表）的概念很重要。

→ 详细内容请见 [[Package包管理器]]

### 4. C# 脚本基础

Unity 使用 C# 作为编程语言。你需要了解 MonoBehaviour 是什么、生命周期方法（Awake、Start、Update、FixedUpdate）的区别、Vector2 的用法、数据类型注意事项等。这是所有脚本编程的基础。

→ 详细内容请见 [[CSharp基础]]

### 5. 输入系统

玩家操作游戏需要输入系统的支持。Unity 有新旧两套输入系统，你需要了解它们的区别，并掌握如何切换和配置。

→ 详细内容请见 [[输入系统]]

### 6. 动画系统

角色的待机、行走、攻击等动作都需要动画来控制。你需要掌握 Animation 窗口创建动画剪辑、Animator 状态机的参数和过渡设置，以及通过代码控制动画参数的技巧。

→ 详细内容请见 [[动画制作]] + [[动画状态机逻辑]]

### 7. Tilemap 地图制作

使用 Tilemap 系统可以快速搭建游戏地图。你需要了解如何创建 Grid 和 Tilemap、如何制作调色板、图层的分层管理（碰撞层和非碰撞层）、以及动画 Tile 的制作。

→ 详细内容请见 [[Tilemap地图制作]]

### 8. 层级切换系统

2D 游戏本质上是一个平面，但我们可以通过排序层级（Sorting Order）和触发器的配合，模拟出"高度"的效果——比如角色走上山坡、进入房屋。这是 2D RPG 中非常重要的视觉技巧。

→ 详细内容请见 [[层级切换系统]]

### 9. 相机跟随（Cinemachine）

让相机平滑跟随玩家移动，同时限制在游戏地图范围内。使用 Cinemachine 包可以省去手动编写相机逻辑的麻烦。

→ 详细内容请见 [[脚本_Cinemachine相机]]

### 10. UI 与血条

游戏界面是玩家与游戏交互的窗口。你需要了解 Canvas 的渲染模式、Canvas Scaler 的自适应设置、Image 组件的 Filled 模式做血条、TextMeshPro 文字显示、以及血条跳动的动画效果。

→ 详细内容请见 [[UI制作与血条]]

### 11. 玩家系统

玩家系统包含三个核心脚本：移动控制、战斗攻击和生命值管理。这些脚本协同工作，构成了玩家角色的完整行为。

→ 详细内容请见 [[脚本_PlayerMovement]]、[[脚本_Player_Combat]]、[[脚本_PlayerHealth]]

### 12. 数值管理器（StatsManager）

当游戏中有多个系统需要共享数值（比如最大生命值、攻击力、防御力等）时，用一个专门的数值管理器来统一管理是最优雅的做法。

→ 详细内容请见 [[脚本_StatsManager]]

### 13. 属性面板 UI（StatsUI）

有了数值管理器，我们还需要一个 UI 界面来把这些数值展示给玩家看，比如在屏幕上显示当前攻击力、防御力等属性信息。

→ 详细内容请见 [[脚本_StatsUI]]

### 14. 敌人 AI 系统

敌人的行为比玩家更复杂，因为它需要"自主决策"。一个完整的敌人 AI 包含移动追逐（检测玩家进入仇恨范围）、战斗攻击（碰撞检测 + 攻击间隔）、生命值管理以及击退效果。

→ 详细内容请见 [[脚本_Enemy_Movement]]、[[脚本_Enemy_Combat]]、[[脚本_Enemy_Health]]、[[脚本_Enemy_Knockback]]

### 15. 经验与升级系统（ExpManager）

当玩家击败敌人后获得经验值，积累到一定数量后升级。这个系统通常需要与数值管理器联动，升级时提升角色的各项属性。

→ 详细内容请见 [[脚本_ExpManager]]

## 学习路线建议

如果你是初学者，建议按照上面的**分点编号顺序**逐步学习。每个部分都建立在前面知识的基础上：

- **第 1-5 步**：掌握 Unity 引擎的基本操作和编程基础
- **第 6-9 步**：构建游戏的世界（场景、地图、相机）
- **第 10-13 步**：实现玩家角色（动画、移动、战斗、UI）
- **第 14-15 步**：完善游戏内容（敌人 AI、经验升级）

祝你开发愉快！
