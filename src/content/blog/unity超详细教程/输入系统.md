# 输入系统

看到错误提示别着急，这是一个很常见的问题。简单来说，你写的代码是旧版输入系统的"语言"，但你的项目设置里"开关"拨到了新版输入系统，导致 Unity 无法理解你的指令。

---

## Unity 的两套输入系统

为了让你更清楚，Unity 目前有两套输入系统：

| 对比项 | 旧版（Input Manager） | 新版（Input System Package） |
| :--- | :--- | :--- |
| 使用方法 | `Input.GetAxis()` 等简单方法 | 基于事件的回调 + Input Actions 配置文件 |
| 配置位置 | Edit → Project Settings → Input Manager | 通过 `.inputactions` 可视化配置文件 |
| 设备支持 | 键盘、鼠标、手柄（基本够用） | 几乎所有设备（键盘、鼠标、手柄、触屏、VR 控制器等） |
| 学习难度 | ⭐ 简单直接 | ⭐⭐⭐ 功能强大但配置复杂 |
| 推荐场景 | 初学者学习、快速原型 | 大型项目、需要复杂输入处理的游戏 |

新项目默认启用新系统。当它检测到你试图使用旧版的 `Input.GetAxis` 时，就会报错。

---

## 旧版 Input Manager 的位置

如果你使用旧版输入系统，可以在以下位置查看和修改输入轴配置：

**Edit → Project Settings → Input Manager**

在输入管理器中，可以看到预设的输入轴（Axes）：
- **Horizontal**：负责监听左右方向键或 A/D 键
- **Vertical**：负责监听上下方向键或 W/S 键

这些轴可以在列表中自行修改，默认设置已经够用。

---

## 常用方法：Input.GetAxis

```csharp
float horizontal = Input.GetAxis("Horizontal");
float vertical = Input.GetAxis("Vertical");
```

`Input.GetAxis` 会返回一个范围在 -1 到 1 之间的浮点数：
- 按下左/A → horizontal 从 0 平滑过渡到 -1
- 按下右/D → horizontal 从 0 平滑过渡到 1
- 松开按键 → 数值平滑归零

这个平滑过渡的特性让角色移动更自然，但如果你想要"瞬间响应"，可以使用 `Input.GetAxisRaw`（返回值只有 -1、0、1 三个值，没有平滑过渡）。

## 新旧版差异的解决方案

这里有三种方案供你选择：

### 方案一：切换回旧版（最快解决）✅

如果你正跟着使用旧版 API 的教程学习，这是最简单直接的方法。

1. 打开 **Edit** → **Project Settings** 窗口
2. 在左侧列表选择 **Player**，然后在右侧找到并展开 **Other Settings**
3. 找到 **Active Input Handling** 选项
4. 将选项从 "Input System Package (New)" 修改为 **"Input Manager (Old)"**
5. 重启 Unity 编辑器，代码就能正常工作了

### 方案二：选择 "Both" 模式（鱼与熊掌兼得）🔄

如果你想让新旧两套 API 在你的项目中同时生效（例如，自己用旧代码但有插件依赖新系统），选择这个模式。

1. 同样进入 **Edit** → **Project Settings** → **Player** → **Other Settings**
2. 将 **Active Input Handling** 选项修改为 **"Both"**
3. 重启 Unity 编辑器即可

这种方式在以后可能需要处理一些输入逻辑上的小冲突，但总体来说是兼容性最好的选择。

### 方案三：全面拥抱新系统（推荐长期方案）🚀

这是 Unity 推荐的长期发展方向，功能更强，也是很多现代游戏项目的选择。

1. **安装 Input System 包**：打开 **Window** → **Package Manager**，在 "Unity Registry" 下搜索 "Input System" 并安装
2. **创建 Input Actions 文件**：在 Project 窗口右键 → **Create** → **Input Actions**，命名为 `PlayerInputActions`
3. **配置输入动作**：双击打开它，创建 "Movement" 动作，路径设为 `Vector2`，并为它绑定 WASD 和方向键
4. **修改移动脚本**：使用 `Move.ReadValue<Vector2>()` 替代 `Input.GetAxis()`

如果你刚开始学习，**方案一（切换回旧版）可能最适合你**，这样可以先专注于游戏逻辑本身，而不是和输入配置作斗争。等你对 Unity 更熟悉了，再回头学习强大的新输入系统。
