# Unity 引擎基础

Unity 是一个游戏引擎——你可以把它理解成一个"超级工具箱"，里面装满了制作游戏需要用到的各种工具。本文档带你熟悉这个工具箱的布局和基本用法。

---

## 编辑器五大面板

打开 Unity 后，你会看到一个被分割成多个区域的窗口。以下是五个最常用的面板：

### 1. Scene（场景视图）

这是你的"工作台"。你可以在场景里选中、移动、旋转、缩放任何游戏对象。场景视图显示的是游戏世界的编辑状态，不是玩家最终看到的画面。

### 2. Game（游戏视图）

这是玩家最终会看到的画面。点击上方的 Play 按钮后，Game 视图会显示游戏运行的实时效果。Scene 和 Game 可以同时开着，方便你边调边看。

### 3. Hierarchy（层级视图）

列出了当前场景中所有游戏对象（GameObject）的列表。你可以在这里创建、删除、父子级嵌套对象。**父子级**的意思是：移动父物体，子物体会跟着移动；旋转父物体，子物体会围绕父物体旋转。

### 4. Project（项目视图）

显示项目文件夹（Assets）里的所有资源文件——脚本、图片、材质、场景等等。你可以把文件直接拖进来添加资源。

> **小技巧**：Project 列表的**右下角有一个滑块**，向左拉图标变小、向右拉图标变大，方便你按需调整显示效果。

### 5. Inspector（检视视图/属性面板）

这是最重要的面板之一。当你选中任何一个游戏对象时，Inspector 会显示这个对象身上挂载的所有**组件**及其属性。你在这里修改数值、拖拽资源、调整参数。

## GameObject（游戏对象）和 Component（组件）

这两个概念是整个 Unity 的基石。

### GameObject

场景中的**每一个东西**都是 GameObject。角色、灯光、相机、空物体、UI 按钮……全都是 GameObject。它本身只是一个空壳子，没有任何实际功能。

### Component

功能是由**组件**提供的。你把组件附加到 GameObject 上，这个对象就有了对应的能力。

**打个比方**：
- GameObject = 一个空白的乐高底座
- Component = 你往底座上拼的乐高块
- 拼上"Sprite Renderer"块 → 底座能显示图片了
- 拼上"Rigidbody 2D"块 → 底座能受重力影响了
- 拼上"Collider 2D"块 → 底座能检测碰撞了

一个 GameObject 可以挂载任意多个组件，它们共同决定了这个对象"是什么、能干什么"。

## 常用组件介绍

以下是在 2D 游戏开发中最常用到的组件：

### Transform（变换组件）

**每个 GameObject 都自带**，无法删除。它记录了对象的位置（Position）、旋转（Rotation）和缩放（Scale）。所有与空间位置相关的操作都离不开它。

### Sprite Renderer（精灵渲染器）

让 2D 图片能够显示在场景中。你可以在这里更换显示的图片、调整颜色、设置排序层级（决定谁遮挡谁）。

### Rigidbody 2D（刚体组件 2D）

**负责所有物理效果**。给对象加上刚体后，它就会受重力影响、可以与其他物理对象发生碰撞。

常用设置：
- **Gravity Scale（重力缩放）**：控制这个物体受多大重力影响。0 表示不受重力（适合顶部视角游戏），1 是正常重力。
- **Body Type**：Dynamic（动态，受物理影响）、Kinematic（运动学，不受物理力但可移动）、Static（静态，完全不移动）。
- **Constraints（约束）**：可以冻结（Freeze）某个轴的位置变化或旋转。比如 2D 游戏中经常冻结 Z 轴的旋转防止角色倒下。

### Collider 2D（碰撞体 2D）

定义物体的"物理轮廓"。常见的有：
- **Box Collider 2D**（盒型碰撞体）
- **Capsule Collider 2D**（胶囊碰撞体）
- **Circle Collider 2D**（圆形碰撞体）
- **Polygon Collider 2D**（多边形碰撞体）

**Is Trigger（触发器）**：如果勾选，碰撞体就变成了一个"感应区域"——物体可以穿过去，但会触发 `OnTriggerEnter2D` 等事件。适合做检测区域、楼梯入口、视野范围等。

### Animator（动画控制器）

控制游戏对象的动画播放和状态切换。配合 Animation 窗口使用。

## 添加资产（导入资源）

将图片、音频等资源导入 Unity 的方法很简单：

1. 直接**从文件夹拖拽**到 Unity 的 Project 面板里的 Assets 文件夹即可
2. Unity 会自动识别文件类型并设置默认导入参数

添加了一组精灵图（[[Sprite与九宫格]]）后，通常需要进行切割设置：
- **Pixels Per Unit（每单位像素）**：设为 64（值越小精灵在场景中越大）
- **Sprite Mode**：设为 `Multiple`（表示一张图里包含多个精灵）
- **Filter Mode（过滤器）**：设为 `Point (no filter)` 可以取消模糊效果，适合像素风格游戏
- **Format（格式）**：设为 `RGBA 32 bit` 色彩模式

然后点击 **Sprite Editor** 打开图像切割编辑器进行切割。

## 脚本相关注意事项

### 脚本重命名的风险

> **重要提醒**：如果脚本重命名了，很可能导致一连串的问题。因为 Unity 内部的序列化引用是基于类名和脚本文件名匹配的。最好的办法就是删除脚本重写一个，而不是直接改名。

### 接口不暴露的排错思路

> 如果脚本中的变量/方法没有在 Inspector 面板上暴露出来，有可能是因为某个方法或变量是 `private` 的。想让它在 Inspector 中显示，需要改为 `public`，或者使用 `[SerializeField]` 属性标记私有的字段。

## 创建脚本

1. 在 Project 面板的 Assets 文件夹里右键 → 新建文件夹，命名为 `Scripts`
2. 在 Scripts 文件夹里右键 → 创建 `C# Script`
3. 命名规范：不同部分首字母分别大写，例如 `PlayerMovement`、`Enemy_Combat`

> 每个新建的 C# 脚本默认继承自 `MonoBehaviour`，关于这个基础类的详细说明请见 [[CSharp基础]]。

## 添加新的包

Unity 的功能可以通过安装包来扩展：
1. 点击菜单栏 `Window` → `Package Manager`
2. 在包管理器左上角选择 `Unity Registry`（Unity 官方注册表）
3. 浏览或搜索需要的包，点击 Install

关于包的详细说明请见 [[Package包管理器]]。
