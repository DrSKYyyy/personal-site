# Tilemap 地图制作

Tilemap 是 Unity 内置的 2D 地图编辑系统。你可以像"画图"一样在地图上铺瓦片（Tile），快速搭建游戏场景。

---

## 准备工作

在开始制作地图前，先将地形精灵图切割好（关于精灵图的切割步骤，参见 [[Sprite与九宫格]]）。

---

## 创建 Tilemap

1. 在 Hierarchy 中右键 → **2D Object** → **Tilemap** → **Rectangular**（矩形网格）
2. 此时创建的是一个名为 **Grid**（网格）的父物体，下面会自动带一个 Tilemap 子物体
3. Grid 是所有地图瓦片的基础网格，Tilemap 才是实际的绘制图层

---

## 创建调色板

在开始铺图块之前，需要先创建一个调色板（Tile Palette）来存放你要使用的瓦片。

1. 点击菜单栏 `Window` → **2D** → **Tile Palette**（调色板）
2. 点击 **Create New Palette** 创建一个新调色板
   - 注意是点击**下面**（不是上面那个 "Active Tilemap"）
   - 上面的选择的是当前在哪个图层上绘制
3. 存储位置可以选择放在精灵图所在的文件夹下
4. 将切割好的精灵图直接拖入调色板窗口（拖到 Default Brush 上方区域，如果被遮住了可以把窗口拉大）
5. 现在你就可以像画图一样在场景中绘制了。调色板上方有一些工具可以使用（选择、移动、画笔、填充等）

> **注意**：创建的调色板会在文件夹下出现一个文件，头部有一个正方体形状，Inspector 中显示为 "(Prefab Asset)"。如果删了这个文件，刚才的调色板就没了。

> **小技巧**：如果搞错了调色板的内容，使用调色板工具栏最右侧的 **Edit（笔的按钮）** 按钮进行编辑。

---

## 设置图层排序

选中 Tilemap 对象，在 Inspector 中找到：
**Tilemap Renderer（渲染器） → Additional Settings → Sorting Layer / Order in Layer**

在这里可以设置瓦片的渲染排序，把地面图层、装饰图层等设置到正确的层级上。

---

## 多图层管理

为了方便管理不同高度的地图元素，建议创建多个 Tilemap 图层，全部放在同一个 Grid 下：

- **Collision-Low（低碰撞层）**：渲染在玩家**下方**且**有碰撞**（地面、墙壁等）
- **Collision-High（高碰撞层）**：渲染在玩家**上方**且**有碰撞**（屋顶、上层平台等）
- **Non-Collision-Low（低非碰撞层）**：渲染在玩家**下方**且**无碰撞**（地面上装饰物、花花草草）
- **Non-Collision-High（高非碰撞层）**：渲染在玩家**上方**且**无碰撞**（树叶、天花板装饰等）

**添加新图层的方法**：
1. 在 Hierarchy 中右键 Grid 父物体 → **2D Object** → **Tilemap** → **Rectangular**
2. 这样就创建了一个新的 Tilemap 子图层
3. 在 Tilemap Renderer 中设置它的排序层级

> 为什么要分层？如果不分层，装饰物放在地面上时，装饰物下方的地面会被"戳洞"（因为覆盖了地形瓦片），而装饰物上方是空的。分层管理可以避免这个问题。

---

## 添加碰撞体

- 给有碰撞需求的图层添加 **Tilemap Collider 2D** 组件
- 选中 Grid 下的对应 Tilemap 子物体
- 添加组件：**Tilemap Collider 2D**
- 它会自动映射到这个图层下的所有图块，不需要给每个瓦片单独添加碰撞体

---

## 动画 Tile 的制作

想让地图上的某些瓦片动起来（比如闪烁的水面、流动的岩浆）？可以使用 Animated Tile（动画瓦片）。

1. 在 Project 面板中，进入存放精灵图的文件夹
2. 右键 → **Create** → **2D** → **Tiles** → **Animated Tile**
3. 在 **Number of Animated Sprites** 中输入动画帧数
4. 在下方的方框中拖入每一帧的精灵图
5. **Speed（速度）**：可以选择最小到最大之间的随机值，也可以保持一致
6. 将这个 Animated Tile 拖入调色板
7. 然后像普通瓦片一样在地图上绘制即可——它会在场景中自动播放动画
